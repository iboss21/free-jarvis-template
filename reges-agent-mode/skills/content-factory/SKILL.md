# Content factory

## Fan-out per research event

```
1 long-form video   original artifact REQUIRED
5 shorts            distinct hooks, not five clips of the same 30 seconds
3 short-vertical    platform-native framing
3 reels
1 thread            DRAFT ONLY — see kb-001 X
5 posts             DRAFT ONLY
1 article           original data section mandatory
1 newsletter section
```

## The variety rule

The QC gate rejects on similarity and repeated structure. Do not try to pass it by paraphrasing. Pass it by **changing the shape of the argument**:

- teardown
- walkthrough of a real build
- comparison with measured results
- failure post-mortem
- live problem-solving
- data analysis of something you collected

Rotate. Never run the same shape three cycles running — check 2 will reject it and the cycle is wasted.

## Originality source

Cheapest reliable original artifact available to this operator: screen capture of real work, own benchmark output, own code, own product telemetry. Prefer these over generated visuals whenever the topic allows. They satisfy check 3 automatically and they are what platform originality policies are written to protect.

## Forbidden

- Health, finance, or legal content with a synthetic persona (kb-001 YouTube class 3)
- Any asset whose only differentiator from a prior asset is swapped nouns
- Publishing directly. You emit assets. The publish skill and QC gate own what goes live
